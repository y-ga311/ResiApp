# トレーニング画像 生成プロンプト

**用途：** レッスン各スライドのビジュアル  
**スタイル共通：** 10代学生向け・ネイビー基調（#1B3A6B）・フラットでやさしいイラスト・文字なし

---

## フォルダ構成

```
public/training/
├── 行動活性化/
├── 認知再構成/
├── 問題解決/
├── アサーション/
└── 睡眠行動療法/
```

**ファイル命名：** `{レッスンID}-{スライドID}.png`  
例：`sk1-l1-s1.png`（行動活性化 L1 の1枚目）

---

## 共通スタイル指示（毎回冒頭に付ける）

```
スマホアプリ向けのやさしいイラストを生成してください。
対象は10代の学生。
スタイル：フラットで現代的なイラスト、丸みのある形、柔らかい光。
カラー：メインは深いネイビー（#1B3A6B）、アクセントは薄いブルー（#DBE8FF）、必要ならやさしいグリーン。
文字・ロゴ・UI枠は入れない。
暗い雰囲気や医療的な雰囲気は避ける。
正方形（1:1）、レッスンカードの中央に載せる用途。
```
