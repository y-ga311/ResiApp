# 実践機能 UIモック — ChatGPT画像生成プロンプト

学習レッスンと日常の記録をつなぐ機能の**画面イメージ図**用。  
ChatGPT（画像生成）に、下の【共通スタイル】→各画面プロンプトの順で貼る。

> 目的：実装前のビジュアル検討用モック。実機UIの厳密な再現ではなく、「ResiAppらしい体験」が伝わること優先。

---

## 【共通スタイル】（毎回先頭に付ける）

```
スマホアプリ「ResiApp」のUIモックアップ画面を1枚生成してください。

【アスペクト比】
縦長のスマホ画面。推奨：9:19.5 または iPhoneの画面比率。正方形・横長は不可。
画面は1枚のスマホフレーム内に収める（実機写真風でもフラットなモックでも可）。

【アプリのトーン】
- 対象：10代〜大学生向けメンタルヘルス／レジリエンス学習アプリ
- やさしい・明るい・医療っぽくない・怖くない
- フラットで現代的なUI、角丸多め、余白あり
- ボトムタブあり（ホーム／トレーニング／チェック／成長／設定 のイメージ）
- ブランドメインカラー：深いネイビー #1B3A6B
- 背景：薄いブルーグレー〜白（#F5F7FB 〜 白）
- カードは白、薄い影、大きめの角丸
- 日本語テキストは崩さない・誤字なし・読みやすい太めゴシック
- 実在する他社アプリのロゴ・キャラクター・商標は絶対に入れない
- 「ResiApp」または機能名の日本語タイトルは入れてよい
- 英単語は最小限（Lv. / XP 程度なら可）
```

## 0. ホーム「今日の実践」ハブ

参考体験：Headspace / Fabulous の「今日やること1つ」

```
（↑共通スタイルを先に貼る）

【画面】ホーム — 「今日の実践」ハブ
【レイアウト】
- 上部：挨拶「おはよう、〇〇さん」と連続日数バッジ（例：7日連続）
- 中央の大きなカード「今日の実践」：スキル色の小さなラベル（例：睡眠）と、行動1つ（例：「昨夜の睡眠を記録する」）、右に矢印
- その下に小さな3カラム：気分チェック／今週のレッスン／成長ポイント
- 下部：ボトムタブ（ホームが選択状態）
【雰囲気】
開いた瞬間に「今日やることが1つだけ分かる」。ごちゃごちゃさせない。
【テキスト例】
今日の実践／昨夜の睡眠を記録／気分はどう？／7日連続
```

## 1. SK01 行動活性化 — デイリー行動リスト

参考体験：Streaks / Habitica（クエスト感は控えめに）

```
（↑共通スタイルを先に貼る）

【画面】行動チャレンジ — 今日の小さな行動
【スキルカラー】
メイン：深いネイビー #1B3A6B／アクセント：やさしいグリーン #34D399／背景：#F0F4FF
【レイアウト】
- タイトル「今日の小さな行動」
- 炎アイコン＋「連続5日」
- チェック可能なリスト3〜4件（例：外に5分出る／好きな曲を1曲／友だちに一言送る）
- 各項目に完了チェック丸と、気分「前→後」の小さな顔アイコン枠
- 下に進捗バー「3/4 完了」と励まし文
【雰囲気】
Habitトラッカー風だがゲーム過多にしない。達成感はあるが落ち着いた学生アプリ。
【テキスト例】
今日の小さな行動／連続5日／外に5分出る／完了したら気分をタップ
```

## 3. SK03 問題解決 — 問題ボード＆次の一手

参考体験：Todoist / Things（仕分けと次アクション）

```
（↑共通スタイルを先に貼る）

【画面】問題解決ボード
【スキルカラー】
メイン：深いオレンジ #EA580C／背景：#FFF7ED／アクセント：#FED7AA
【レイアウト】
- タイトル「いま解く問題」
- 上部カードに問題文（例：提出物が遅れそう）
- 2列の仕分け：「動かせる」「動かせない」に小さな付箋カードが数枚
- 下部に「次の一手」セクション：チェック可能な1〜2タスク（例：先生に相談メールを下書き）

【雰囲気】
ホワイトボードをスマホに圧縮した感じ。オレンジのアクセントで前向き。
【テキスト例】
いま解く問題／動かせる／動かせない／次の一手／先生に相談する

## 5. SK05 睡眠 — 睡眠日誌（メイン案）

```
（↑共通スタイルを先に貼る）

【レイアウト】
- タイトル「睡眠日誌」
- 上半分：昨夜のサマリーカード（就寝 0:40／起床 7:10／満足度 6/10）星や月のやさしいアイコン

## 使い方メモ

1. ChatGPTに【共通スタイル】を貼る  
2. 続けて見たい画面のプロンプトを1つ貼る（1回につき1画面が綺麗）  
3. 色や文言を変えたいときは、スキルカラー表と【テキスト例】だけ差し替える  
4. 「もっと既存アプリっぽく／もっとシンプルに」と追加指示すると調整しやすい
