## 使い方

1. 下の該当設問の ``` 〜 ``` を**全部**コピーして ChatGPT に貼る  
2. ダウンロードしたら、指定の**ファイル名**にリネームして**保存先**へ  
3. **1回につき1枚**  
4. 文字サイズや位置がズレたら、同じプロンプトに続けて指示：  
   `固定レイアウトを厳密に守り、番号バッジ→見出し→点線→設問文→補足→下半分イラストの順で、フォントサイズを指定どおりに描き直してください。`

### 固定レイアウト（全設問共通・要約）

```
上 6% … 番号ピル「Qn / 総数」（小・約2.2%）
     … 見出し（大・約5.0–5.5%）
     … 点線＋中央マーク
     … 設問文（中・約3.0–3.2%／最大3行／カッコなし）
     … 補足（最小・約2.0%）
下 55% … イラストのみ（文字と重ねない）
```

   - 画面下側 約55%（下端から上へ）
   - テキスト領域（上側 約42%）と絶対に重ねない
   - イラストが文字に食い込まないよう余白を確保

禁止（ばらつきの原因になるため）：
- 設問ごとにフォントサイズや余白を変える
- 番号バッジを省略する／形を変える
- 設問文をカッコで囲む／囲まないを混在させる（囲まないで統一）
- 見出しを極端に大きくしてイラストを圧迫する
- 選択肢ボタン・回答UIを描く
- 余計な英語ロゴ
