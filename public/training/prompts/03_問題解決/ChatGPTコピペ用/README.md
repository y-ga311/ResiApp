# 問題解決：ChatGPT画像生成コピペ用

既存画像を除外した、共通スタイル結合済みのプロンプトです。
各レッスンファイル内のコードブロックを1つずつコピーし、ChatGPTへ貼り付けてください。

|---|---|---:|---|
| L2 | 問題を明確に定義する | 5枚 | `L2_問題を明確に定義する_コピペ用.md` |

合計：34枚

## 保存後の流れ

1. ChatGPTから画像をダウンロードし、元のダウンロード名のまま `public/training/問題解決/` に保存します。
2. 保存が終わったら、どのレッスンまで生成したかを伝えてください。
3. 画像を目視確認し、各プロンプトの内容と照合して正式ファイル名へ変更します。
4. 既に正式名で存在する画像は上書きしません。重複や判別不能な画像は保留して報告します。
